# How Intelligence Grows · 大模型与 Agent 技术资料库

面向公开展示的大模型与 Agent 研究资料站，统一收录文档、视频、论文与课程专题的结构化 HTML 笔记。

站点现收录 85 份完整 HTML 笔记，其中文档资料 12 份、视频资料 25 份、论文资料 48 份。视频笔记配有独立的详细讲稿子页面，可在总结与讲稿之间直接跳转。内容按“LLM 后训练基础”、“Agentic RL 与行为训练”、“Long-Horizon agent”、“Harness 与 Agent 系统工程”、“Skill、Memory 与 Context”、“自进化与 AI4AI”、“Benchmark 与评测”、“产业与商业分析”、“专题学习”九个方向分组，并支持方向筛选、资料类型筛选与关键词搜索。

Long-Horizon agent 按综述、任务架构、状态与上下文维护、主动记忆、反思回退、过程验证和长程判断组织核心论文。每篇资料保留一个主方向，交叉方向通过筛选关联训练、记忆与评测材料。
