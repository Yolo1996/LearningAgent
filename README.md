# How Intelligence Grows · 大模型与 Agent 技术资料库

面向公开展示的大模型与 Agent 研究资料站，统一收录文档、视频、论文与课程专题的结构化 HTML 笔记。

站点现收录 122 份完整 HTML 笔记。视频笔记配有独立的详细讲稿子页面，可在总结与讲稿之间直接跳转。内容按后训练、Agentic RL、长程智能体、Agent 架构与工程、Skill / Memory / Context、自进化、Benchmark、产业与商业分析、AI Coding、AI 产品与组织实践、专题学习十一个方向分组，并支持方向筛选、资料类型筛选与关键词搜索。

Long-Horizon agent 按综述、任务架构、状态与上下文维护、主动记忆、反思回退、过程验证和长程判断组织核心论文。每篇资料保留一个主方向，交叉方向通过筛选关联训练、记忆与评测材料。

长程 Agent 专题《长程执行可靠性：免训练 Agent 论文与技术图解》围绕规划与执行控制、上下文与记忆管理、验证与错误恢复三条主线组织，并收录论文原始方案图。论文索引另提供长程智能体十篇论文专题与离线下载合集。

支持“评估与可靠性”“研究方法与成长”跨方向标签，可与方向、资料类型和关键词组合筛选。AI Coding 综合教程保留专题主归属，同时关联 AI Coding 方向。
